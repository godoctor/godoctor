The Go Doctor

A Go refactoring tool.

This project is deprecated.
gopls — the official Go language server maintained by the Go team — has superseded the Go Doctor and provides equivalent (and more) refactoring functionality. New users should use gopls; existing users are encouraged to migrate. The source code and these archived docs remain available for historical reference.
